## 3. Skyfall AI `SKY-001` 工程世界模型深度技术调研

### 3.1 团队背景与问题定义

Skyfall AI 由前微软收购的深度学习自然语言公司 **Maluuba** 联合创始人 **Sam Pasupalak** 与 **Kaheer Suleman** 联手 **Sumit Pasupalak** 创立，历时 18 个月研发后于 `2026-10-19` 发布 `SKY-001`。其核心论点指出：机械工程（CAD）与建筑工程（BIM）本质上是**三维空间中的序列构造与层级装配问题**，而现有自回归大语言模型（LLM）将其强行压平为一维文本/脚本（如单次生成数百行 Blender Python 或 CadQuery 脚本），导致三大结构性瓶颈：

1. **缺乏中间三维物理状态（No Intermediate 3D State）**：LLM 在生成第 80 步布尔切割代码时，无法“看见”前 79 步累积生成的三维实体几何，极易发生拓扑自相交或空间漂移。
2. **扁平串行长链（Long Sequential Chains）**：一个包含 100 个零件、每零件 100 个构造步的装配体需要 $10,000$ 步串行推理，延迟高达数十分钟且错误逐步累积。
3. **训练数据粒度失配**：现有公开 3D 数据集（如 PartVerse）每物体零件数中位数仅 **`6` 个（p99 为 `33` 个）**，而真实工业装备动辄数百至数千个零件。Skyfall 构建的自有 CAD 语料库每物体零件数中位数达 **`288` 个（p99 达 `4,180` 个）**（例如：Fat Bike `988` 零件 vs 公开 BMX `8` 零件；Ducati 900SS `751` 零件 vs 公开 Harley `34` 零件；四足机器人 `542` 零件 vs 公开机甲 `85` 零件）。

### 3.3 装配树关键路径压缩数学验证（Critical-Path Scaling）

设某工程装配体共有 $N$ 个树节点、$L$ 个叶节点（零件），则内部拆分节点数为 $N - L$，树深为 $D$，每个零件构造步数为 $S$，并行推理 Worker 容量为 $W$：

- **扁平串行自回归总步数（Flat Sequential Steps）**：
  $$T_{\text{flat}} = (N - L) + L \times S$$
- **SKY-001 分层并行关键路径步数（Hierarchical Sequential Steps）**：
  $$T_{\text{tree}} = D + \left\lceil \frac{L}{W} \right\rceil \times S, \qquad \text{Speedup} = \frac{T_{\text{flat}}}{T_{\text{tree}}}$$

由 [`simulator/sky001_and_19model_verifier.py`](simulator/sky001_and_19model_verifier.py) 在 $S=100, W=128$ 下对官方 4 个 Showcase 资产的精确验算结果如下：
