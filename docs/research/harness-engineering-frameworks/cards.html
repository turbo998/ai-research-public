MY TAKE · AI SOLUTION ARCHITECT PLAYBOOK 7 / 7

Architect's Verdict: Govern Upper SDLC Phases with HVE 4-Tier Artifacts + `/clear`, and Power the Runtime with DSH Seams + Claude SDK

No single framework dominates every layer—elite AI Solution Architects combine HVE's deterministic phase-reset governance on top with DSH's Cordis capability seams and Claude Code's runtime loop underneath.

✅ Good Fit (When to Adopt)

1. Adopt DeepSeek DSH Microkernel:
• Remoting Bash/LSP/File tools into SSH or container sandboxes without forking tool definitions (3-Role Seam).
• High-frequency 20+ step tool orchestration via dsh-tool-executor-ptc (run_code) to eliminate intermediate token bloat.
• Federating Claude Code, Codex, ACP, and in-process forked children under one parent session.

2. Adopt Claude Code & Agent SDK:
• Embedding an autonomous dev/CI loop with strict cumulative max_budget_usd enforcement across parent and subagents.
• Mounting 100+ enterprise MCP tools using ToolSearch lazy schema loading and readOnlyHint parallel batches.

3. Adopt Microsoft HVE Core:
• Scaling standardized SDLC workflows (Research → Plan → Implement → Review) across 100+ engineers using inter-phase /clear + .copilot-tracking/ disk state and Vally CI behavior gates.

⛔ Not For (Anti-Patterns to Avoid)

1. Never Run End-to-End SDLC in One Uncleared 200K Session:
• Without /clear or subagent isolation, system prompt share drops to 1.5%, causing rampant phase-skipping.

2. Never Mutate Node-0 System Prompts Mid-Session:
• Injecting volatile timestamps or directory trees into message 0 invalidates 100K+ tokens of prefix KV cache (use DSH in-history append or static CLAUDE.md prefixes).

3. Never Mix Native & PTC Surfaces Within One Agent Scope:
• Under DSH PTC mode, direct model calls to SDK-only tools fail with UNKNOWN_TOOL; intermediate VM memory is also unbounded by bytes.

4. Never Force Heavy Team DAGs onto 3-Turn Scripts (S11 ✕):
• Use memory-only dsh-sdk-minimal or single-shot query().

Enterprise Reference Blueprint: The Golden Hybrid Harness Stack Production Ready · 97.6%

[Upper SDLC Governance Layer — HVE Core] Prompts (.prompt.md) → Agents (.agent.md) → Instructions (applyTo) + Skills, enforcing inter-phase /clear with .copilot-tracking/ disk artifacts + task-challenger red-teaming + Vally CI evals.
[Lower Microkernel Runtime — DSH + Claude SDK] Cordis ctx.subagents federating subagent-claude-code and in-process forks, readOnlyHint + PTC run_code batching, in-history prompt updates (94.2% KV cache hit), and hard max_budget_usd caps.
