MY TAKE

Why Microsoft Decision-1 stays the #1 production choice after OpenAI Decisions joins

✅ Good fit
  • Microsoft Decision-1 as default cloud router on Azure AI Foundry: 100% neutral accuracy (94.2% cheap), $7.6–$8.6/1M cost (3.3x cheaper than OpenAI Decisions, 16x cheaper than gpt-4.1-mini), ~550 ms P50, and clean 0.60 threshold gating
  • TypeSafe Jev when maximum instruction immunity (39..40/40 across all 4 variants, 0 false blocks at 0.60) and lowest cloud latency (~330 ms P50) justify ~3x Decision-1's price ($21.7–$24.1/1M)
  • Neutral routing instructions ('Pick the option whose description best matches...') while encoding tier boundaries inside candidate descriptions (+12.5% on OpenAI Decisions, +5.8% on Decision-1)
  • OpenAI Decisions for teams already on an OpenAI 1P key needing a fast (~400 ms P50) drop-in endpoint under neutral/bare instructions (92.5%–95.0%)
  • Setting reasoning_effort='none' whenever using a reasoning LLM (gpt-6-luna) as a prompt-based router (+15.0 to +18.3 pts accuracy, -400 ms latency, -37% cost vs default reasoning)
⛔ Not for
  • Combining OpenAI Decisions with cost-saving prompt instructions ('prefer cheaper when simple'): accuracy drops to 80.0% (32/40) and 14/20 (70%) on implicit Set B requests
  • Relying on a 0.60 confidence gate with OpenAI Decisions: 50% of its misses (24/48 across v2.4.1) have p >= 0.60 (up to 0.78), failing silently without triggering fallback
  • Calling /openai/v1/decisions on Azure AI Foundry (returns HTTP 404; Foundry serves Decision-1 at /providers/microsoft/v1/systemone instead)
  • Leaving default reasoning enabled on LLM routers (gpt-6-luna default drops to 72.5%–75.8% accuracy and flips choices across rounds on 11–13/40 prompts)
  • Commercial production use of OpenJev 27B weights (CC BY-NC 4.0 non-commercial license) or 5-way general model routing with Laya 0.3.20 (47.5%–52.5% accuracy)
