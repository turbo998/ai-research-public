MY TAKE · 3-WAY DECISION GUIDE & HYBRID RELAY WORKFLOW 7 / 7

Combine FAF v2 (Customer SDLC) + AGENT-FORGE (Repo Compiler) + HVE-Core (RPI & Challenger)

The three toolkits operate at complementary layers: FAF governs business/architecture decisions, AGENT-FORGE synthesizes stack-specific .github/ assets, and HVE-Core enforces context-cleared RPI execution and adversarial review.

✅ Good Fit (When to Use Which)

  • Use FAF (faf-agents) for Enterprise SDLC Delivery: Customer scoping, 9-gate AI prioritization (P1 Go: 78.0/90.9/87.5), C4 specs, live Azure retail TCO estimates, and 8-area weighted Solution Accelerator scoring (>70% customize vs. <40% greenfield).
  • Use AGENT-FORGE (@agent-forge-copilot/cli) for Custom Repo Synthesis: Auto-generating and validating bespoke .github/agents/, prompts/, instructions/, skills/, and hooks/ across 14+ tech stacks (8/8 passed, 0 warnings).
  • Use HVE-Core (microsoft/hve-core) for High-Rigor Engineering & Governance: 275 battle-tested artifacts across 14 collections, strict /clear RPI context isolation in .copilot-tracking/, OWASP/RAI/A11y planners, and task-challenger cold interrogation.
  • The 3-Way Power Relay: Scope & architect with FAF → generate bespoke domain agents with AGENT-FORGE → execute and stress-test complex features with HVE-Core RPI + Task Challenger.

⛔ Not For (Anti-Patterns & Gotchas)

  • Do Not Use AGENT-FORGE as a Business/Architecture Consultant: It ships zero Azure Bicep Landing Zones, customer PRD/C4 templates, or accelerator scorecards.
  • Do Not Skip /clear Between HVE-Core RPI Phases: Accumulating chat history across task-researcher and task-implementor defeats RPI's anti-hallucination guarantee; always rely on .copilot-tracking/ files.
  • Never Upgrade FAF via VS Code UI Reinstall Alone: VS Code reuses cached plugins in %APPDATA%\Code\agentPlugins; close VS Code and delete the cached folder before reinstalling.
  • Watch Out for copy-assets.mjs in AGENT-FORGE Source Builds: Building @agent-forge-copilot/cli@0.3.0 from git requires copying src/cli to dist/cli after tsup because src/template was removed.
