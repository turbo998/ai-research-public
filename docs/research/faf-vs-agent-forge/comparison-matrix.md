## 2. 深度专题对比：为什么两个项目都叫“Agent Forge”？

在调研过程中，最容易引发混淆的是二者的命名高度重合：
- `customer-success-microsoft/faf-agents` 的主标题是 **`Agent Forge (FAF)`**，其插件市场名称为 **`agent-forge-plugins`**，历史标签中亦称 **Field Agent Framework / Factory Agent Forge**。
- `microsoft/agent-forge` 的仓库名直接叫 **`agent-forge`**，而在其源码 `src/lib/merger.ts` 第 8 行中可以看到：
  ```typescript
  const GENERATED_MARKER = '<!-- Generated by AGENT-FORGE -->';
  const LEGACY_MARKER = '<!-- Generated by SpecForge -->';
  ```
  这证明 `microsoft/agent-forge` 最初名为 **SpecForge**，随后更名为 **AGENT-FORGE** 并以 `@agent-forge-copilot/cli` 发布到 npm。

**一句话记忆法则**：
> - **FAF (`customer-success-microsoft/faf-agents`)** 是 **“给你派来一队懂 Azure AI 和 Fabric 的微软资深顾问 Agent”**；
> - **AGENT-FORGE (`microsoft/agent-forge`)** 是 **“给你一台能根据你的代码库自动制造 `.github/` 专属 Agent 的机器”**。
