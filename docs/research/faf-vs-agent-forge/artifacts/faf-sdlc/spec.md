## 2. C4 Level 3 — Mathematical & Component Contracts

### 2.1 Component A: `AnalyticalTwoBoneIKSolver`
Given Hip origin $H = (x_h, y_h)$, Pedal target $P(\theta_c) = B + r_c(\cos\theta_c, \sin\theta_c)$ (where $B = (x_b, y_b)$ is the bottom bracket and $r_c$ is crank length), femur length $L_1$, and tibiotarsus+tarsometatarsus length $L_2$:
1. **Target Distance Clamping**:
   $$d = \min\!\left(\max\!\left(\|P - H\|_2,\; |L_1 - L_2| + \varepsilon\right),\; L_1 + L_2 - \varepsilon\right)$$
2. **Law of Cosines Knee Interior Angle**:
   $$\cos\alpha = \frac{L_1^2 + d^2 - L_2^2}{2 L_1 d}, \quad \alpha = \arccos(\text{clamp}(\cos\alpha, -1, 1))$$
3. **Forward-Bending Avian Knee Joint Position $K = (x_k, y_k)$**:
   With base hip-to-pedal angle $\beta = \text{atan2}(P_y - H_y, P_x - H_x)$, the knee joint is solved deterministically as:
   $$K = H + L_1 \left(\cos(\beta - \alpha),\; \sin(\beta - \alpha)\right)$$

### 2.2 Component B: `DrivetrainPowerModel`
Mechanical power $W$ (Watts) as a function of cadence $C$ (RPM), gear ratio $G$, headwind $v_w$ (km/h), and fish payload mass $m_f$:
$$v_{\text{ground}} = \omega_c \cdot G \cdot R_{\text{wheel}}, \quad W = \left(c_{\text{roll}}(M_0 + m_f)g + \frac{1}{2}\rho C_d A (v_{\text{ground}} + v_w)^2\right) v_{\text{ground}}$$

### 2.3 Component C: `XRayKinematicsOverlay`
When `xrayMode === true`, renders high-contrast cyan/amber engineering callouts: Hip pivot $H$, Left/Right Knee joints $K_L, K_R$, Pedal spindles $P_L, P_R$, Crank circle $r_c$, velocity vectors $\vec{v}$, and live joint angle arcs ($\theta_{\text{hip}}, \theta_{\text{knee}}$).
