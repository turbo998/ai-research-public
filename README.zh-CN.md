> **Executive Summary / 核心结论概览**：
> 本仓库是由 **turbo998** 维护的面向可复核证据（Evidence-Backed）与确定性仿真验证的公开 AI 工程研究总库。围绕 **“计算与状态解耦（Compute-State Decoupling）”**、**“平台级零信任硬边界（Never Trust the Prompt）”** 与 **“确定性验证脚手架 + 7-Card 4:5 密封基准报告”** 三大核心工程公理，系统覆盖 **五大研究支柱（5 Pillars · 15 个公开及跨库专题）**：
> 1. **云原生 Agent 基础设施与高可用韧性（Cloud Agent Infra & Resilience）**：实测第五代 AMD EPYC Turin (`Standard_D96as_v7`) 将 E2B 沙箱恢复压缩至 **`108 ms` Base / `132 ms` Code-Interpreter V1（提速 `54.8%`）**，单 VMSS 规模集 **261 台节点** 支撑 **100,000 并发 MicroVM**；源码级攻克 `E2B × Nomad` 在 `yamux` 10–40s 断连检测与 Leader 20–30s 心跳预算间的竞态，实现 **`<=35s` 抖动零误杀**。
> 2. **前沿模型、世界模型与决策路由基准（Frontier Models & Decision Routing）**：在 19 模型 × 11 题 Coding Agent 评测中，**`Claude Haiku 5.5`（`99.24` 分，`$0.33`）** 相比 `Haiku 4.5` 降本 **`91.6%`** 跃居总榜 **#4**（仅次于 `Fable 5.1` `99.77` 与 `Opus 5.5` `99.68`），`SKY-001` 工程世界模型实现 **`98.44x` 关键路径加速**；在 Switchyard 3,880 次路由评测中，删去一句省钱偏置提示即令 **`Microsoft Decision-1`、`TypeSafe Jev` 与 `OpenJev 27B` 同时达成 `40 / 40`（`100%`）满分**，其中 `Decision-1` 成本仅 **`$7.6 / 1M`**。
> 3. **上下文工程、工程脚手架与多智能体框架（Harnesses, Frameworks & Skills）**：实装对比 **FAF v2 (`faf-agents`)**、**Microsoft AGENT-FORGE CLI** 与 **Microsoft HVE-Core (`v3.3.101`)** 并构建 60FPS 鹈鹕骑自行车同屏竞技场（[`pelican-arena.html`](docs/research/faf-vs-agent-forge/pelican-arena.html)）；结合 `SKILL.md` 三层渐进式披露架构削减 **`85%+` 初始上下文开销**。
> 4. **零信任治理、FinOps 经济学、红蓝对抗与 Agentic Commerce（Governance, Red Team & Commerce）**：建立 **Entra Agent ID 双重归属 + APIM 三级配额熔断**、间接提示词注入防御以及 **Microsoft Web IQ × ACP/UCP 幂等结账（`380 ms`）× AP2/x402 硬件签名支付熔断**。
> 5. **个人智能体、桌面 OS 集成与开源许可审计（Personal, Desktop & Vertical Agents）**：深度横评 **Meta Muse、Grok Bot、OpenAI dot、Gemini Spark、Instinct** 五款产品与 **Omarchy Agent** 174 项安全契约断言、**LocalJev (`OpenJev 27B` / `Laya 8B`)** 商用合规边界。
